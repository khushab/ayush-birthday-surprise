# A surprise for Ayush 🎁

A small React birthday page: a present to unwrap, a cake with candles to blow out, and a few wishes.

**Live site:** https://khushab.github.io/ayush-birthday-surprise/

## Personalise it

- **Name, message, wishes, candles, sign-off:** edit `src/config.js`.
- **Link preview text (WhatsApp, iMessage, etc.):** edit the `<title>` and `og:` tags in `index.html`.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages through `.github/workflows/deploy.yml`.
